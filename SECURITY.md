## Reporting a Vulnerability

As this platform interacts with market data, financial models, and potentially execution accounts, security and integrity are paramount.

If you discover a security vulnerability or credential exposure risk:

1. **Do not create a public GitHub issue.**
2. Send an email directly to the maintainer: **1011raghavgoyal@gmail.com**.
3. Include:
   - Description of the vulnerability and attack vector.
   - Minimal reproducible proof of concept.
   - Any suggested mitigations.

You will receive an acknowledgment within 48 hours, followed by updates on triage and patch deployment.
